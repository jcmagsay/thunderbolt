# Engineering Change Proposal Details

These documents contain the implementation detail behind the [Engineering Quality Improvement Proposal](../engineering-improvement-plan.md). They translate repository-visible observations from [Engineering Quality, CI, Security, and Operations](../engineering-quality.md) into independently reviewable areas.

They are contributor recommendations rather than an approved roadmap. Maintainers may have additional controls, private security work, and roadmap context. Potentially applicable security findings should follow the private process in [`SECURITY.md`](../../../SECURITY.md).

Each proposal separates repository observations from options for maintainer consideration. Counts are point-in-time measurements from this branch, not permanent benchmarks. Missing repository configuration is reported as “not identified” rather than proof that an organization-level control does not exist.
